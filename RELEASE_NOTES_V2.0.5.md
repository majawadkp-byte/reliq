# RELIQ Solutions V2.0.5 — Build 205

## Quotation & WhatsApp workflow
- New Quotations workspace with customer/phone search.
- Create quotations without posting stock or accounting.
- Valid-until date, discounts, delivery/other charges, notes and PDF preview.
- WhatsApp Standard quotation sharing without Meta API.
- Quotation lifecycle: Draft, Sent, Converted.
- Convert a quotation to a held sale, then finish it in Sales / POS.
- Communication log foundation records WhatsApp preparation/open actions without falsely claiming delivery/read status.
- Database schema 26 adds quotations, quotation items and communication history.

## Safety
Quotation creation does not reserve/deduct stock. Stock validation remains at final sale posting.

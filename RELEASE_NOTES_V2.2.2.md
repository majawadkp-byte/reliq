# RELIQ Solutions V2.2.2 — UI Readability & Workflow Fixes

## Visual system
- Removed abstract wallpaper from all post-login workspaces. Operational pages now use a calm theme-aware plain gradient while retaining RELIQ glass surfaces.
- Replaced the login wallpaper with the newly supplied `login-wallpaper.jpg` artwork.
- Improved light-mode floating field labels and focused borders: electric lime is reserved for dark mode; light mode uses a high-contrast deep teal.
- Improved light-mode tab indicators (including Inventory Intelligence Insights / Stock Decisions).

## Sales / POS
- Out-of-stock products are now selectable for feedback rather than silently disabled.
- Selecting/scanning an unavailable stocked product shows a prominent red `OUT OF STOCK` warning with product name and current stock.
- Out-of-stock product tiles receive a stronger error border and unavailable suggestion actions use an error icon.

## Sales History
- Sales History is rebuilt/refetched whenever it is opened from navigation, so today's invoices appear automatically without re-clicking Today or another date filter.

## Day Book
- Opening Cash, Add / Remove Cash and Close / Count Cash cards now use a consistent action area and bottom-aligned primary buttons.

## Reports
- Purchase/trend chart lines now use a darker accessible olive in light mode so they remain visible against white report cards.
- Sales trend uses the stronger RELIQ teal-blue chart token for improved contrast.

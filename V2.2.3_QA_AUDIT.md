# V2.2.3 UI / Performance QA Audit

## Consistency rules
1. Abstract artwork is login-only.
2. Working pages use calm theme backgrounds and readable cards/tables.
3. Electric lime is an accent/action color, not light-mode body text.
4. Secondary/help text should use `Theme.of(context).colorScheme.onSurfaceVariant` / `V3Style.mutedFor(context)`.
5. Form labels and selected indicators use `V3Style.labelAccent(context)` when a branded accent is needed.
6. Dividers should come from the active theme instead of fixed pale colors.
7. Dense data screens prioritize opacity/readability over decorative glass.

## Report performance path
- Report summary: one indexed SQLite aggregate query.
- Daily trend: saved analytics snapshot + background refresh when dirty/stale.
- Common 30-day summary/trend: warmed at idle after app startup.
- Tax: one aggregate database round-trip.
- P&L: one financial aggregate round-trip + one grouped-expense query.
- Detail rows remain lazy-rendered with `ListView`; exports remain off the UI isolate.

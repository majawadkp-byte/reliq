# RELIQ Solutions V2.0.3 (Build 203)

- WhatsApp Standard invoice sharing from Sales History without Meta API setup.
- Customer WhatsApp number and preferred document delivery method.
- Configurable default WhatsApp country code and invoice message template.
- Up to four company/legal custom document fields (GSTIN, Drug License No., VAT/CR, etc.) with invoice visibility.
- Invoice PDF renders enabled custom fields.
- Database schema 24 adds customer WhatsApp and preferred delivery fields.

WhatsApp Standard opens WhatsApp with the recipient and prepared message. It does not silently send messages or claim delivery confirmation. The invoice PDF remains available through RELIQ Print/PDF for user attachment.

# RELIQ V2.2 Design System

## Visual hierarchy
1. **Brand canvas** — abstract RELIQ artwork. Full strength on authentication; low opacity inside the workspace.
2. **Glass chrome** — navigation, top bar, dashboard hero, dialogs and shared section cards.
3. **Operational surfaces** — high-opacity cards/tables/forms where sustained reading matters.
4. **Lime action layer** — `#E1FF05` reserved for primary actions, focus, selection and brand emphasis.

## Semantic rules
Never choose text color from the background by hand in a feature screen. Prefer `Theme.of(context).colorScheme.onSurface`, `onSurfaceVariant`, or helpers in `ReliqSurface`.

Avoid hard-coded white/black for normal text. White is appropriate only on deliberately dark brand surfaces; dark ink is appropriate only inside deliberately light document/print previews.

## Glass
`ReliqGlass` uses translucent theme-aware fill, a low-contrast border, shadow and BackdropFilter blur. Do not place dozens of blurred layers inside large scrolling tables; use theme Card surfaces there to protect rendering performance.

## Backgrounds
- Login: full `reliq_background_dark.jpg` / `reliq_background_light.png`.
- Workspace: same assets at low opacity with a readability wash.
- Dense data surfaces: Card/DataTable opacity stays high enough to separate data from artwork.

## Responsive behavior
The login story panel is shown from 900px upward. Below that breakpoint the authentication card becomes the primary composition and includes a compact RELIQ lockup.


## V2.2.8 interaction refinement
- Customer/Supplier search fields use frosted surfaces and contextual Cmd/Ctrl+F.
- Internal surfaces keep the calm operational background while using translucent/frosted chrome rather than login artwork.

## V2.2.9 reflective-glass refinement

- Wide login follows the supplied reference composition rather than treating the wallpaper as a full-window background.
- Authentication surfaces use backdrop blur plus a restrained reflection gradient and one-pixel edge sheen.
- Shared `ReliqGlass` surfaces inherit subtle reflections behind content; operational text and data stay above the reflection layer for contrast.
- Exact supplied dark/light login artwork is used as the source asset.

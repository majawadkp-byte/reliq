RELIQ Solutions V2.1.0 patch for V2.0.7

1. Back up the customer database before first launch.
2. Extract this patch over the V2.0.7 Flutter source root.
3. Run:

   flutter clean
   flutter pub get
   flutter analyze
   flutter run -d macos

Database schema upgrades automatically from 26 to 27.
V2.1.0 repairs the quotation/communication schema-26 migration path as part of the upgrade.

Important Smart Buying rule changes:
- Active out-of-stock products remain in intelligence.
- Disabled products remain excluded from operational intelligence.
- Dormant/non-purchasable/non-active-lifecycle products do not auto-generate purchases.
- Negative stock becomes a stock-count discrepancy, not extra purchase demand.
- MOQ/order multiple is applied only after an eligible positive need exists.

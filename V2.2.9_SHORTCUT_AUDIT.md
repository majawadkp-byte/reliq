# RELIQ V2.2.9 Keyboard Shortcut Audit

## Global navigation

- Alt+1 — Morning Brief
- Alt+2 — Sales / POS
- Alt+3 — Receive Purchase
- Alt+4 — Products & Barcodes
- Alt+5 — Customer Ledgers
- Alt+6 — Supplier Ledgers
- Alt+7 — Payment Activity
- Alt+8 — Reports
- Alt+9 — Business Action Center

V2.2.9 routes Alt+1…9 through `HardwareKeyboard` using physical number-row keys, with numpad support. This specifically avoids macOS Option-key character translation interfering with navigation shortcuts.

## Global application commands

- Cmd+F (macOS) / Ctrl+F (Windows) — Universal RELIQ Lookup: products, customers and suppliers
- Cmd+K / Ctrl+K — Command Palette
- Cmd+R / Ctrl+R — Refresh/rebuild the active workspace
- Cmd+, / Ctrl+, — Settings
- Shift+? — Keyboard Shortcuts help

## Universal lookup behavior

- Product result — remains in the lookup dialog and opens the existing full product detail view.
- Customer result — opens Customer Ledgers and filters to the selected customer.
- Supplier result — opens Supplier Ledgers and filters to the selected supplier.

Screen-local Cmd/Ctrl+F handlers were deliberately removed from POS, Purchases, Products, Stock Adjustment, Customer Ledgers, and Supplier Ledgers so Cmd/Ctrl+F means the same thing everywhere.

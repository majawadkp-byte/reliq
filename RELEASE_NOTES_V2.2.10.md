# RELIQ Solutions V2.2.10 — Party Ledger Detail

## Customer & supplier ledger behavior
- Clicking a customer or supplier row/name now opens a dedicated full ledger page instead of opening Edit.
- Edit is now an explicit pencil button on each customer/supplier row.
- Universal RELIQ Lookup customer/supplier results now continue into the selected party's ledger detail automatically.

## Full ledger history
The new party ledger page combines:
- invoices / purchases,
- receipts / supplier payments,
- customer / supplier returns that affect the account balance,
- opening balances and accounting debit/credit adjustments,
- running account balance,
- current outstanding/payable, overdue value, credits/advances and open-document totals.

## Operations from the ledger
Customer ledger:
- Receive Payment
- Edit Customer
- Preview Statement
- WhatsApp Statement
- Payment Reminder (when money is outstanding)
- Communication History

Supplier ledger:
- Pay Supplier
- Edit Supplier
- Preview Statement
- WhatsApp Supplier
- Communication History

## UI
- Ledger detail uses the RELIQ frosted/glass surface system.
- Customer/supplier list rows are less cluttered: repeated secondary operations live in the full ledger screen.
- No database migration. Database schema remains 31.
